\section{Vue d'Ensemble du Projet}

\subsection{Contexte et Objectifs}

Terrasse Bleue est un café-restaurant situé à Essaouira, Maroc, qui souhaite digitaliser ses commandes pour améliorer l'expérience client et optimiser ses opérations.

\textbf{Objectifs principaux :}
\begin{itemize}
    \item Digitaliser la consultation du menu
    \item Permettre la prise de commandes via application mobile
    \item Réduire les erreurs de commande manuelle
    \item Offrir une interface de gestion pour le personnel
    \item Permettre le paiement en ligne sécurisé
    \item Assurer le suivi en temps réel des commandes
\end{itemize}

\subsection{Applications Développées}

Le système comprend trois applications principales :
\begin{enumerate}
    \item \textbf{Application Mobile Client} (React Native + Expo)
    \item \textbf{Dashboard Restaurant/Admin} (Next.js)
    \item \textbf{Menu Public} (Next.js avec QR Code)
    \item \textbf{API Backend} (NestJS)
\end{enumerate}

\section{Sécurité et Paiement}

\subsection{Mesures de Sécurité}

\begin{itemize}
    \item \textbf{Authentification :} JWT avec rotation des refresh tokens
    \item \textbf{Mots de passe :} Hashage Argon2id
    \item \textbf{API :} HTTPS obligatoire, validation DTO, rate limiting
    \item \textbf{RBAC :} Rôles CUSTOMER, STAFF, MANAGER, SUPER\_ADMIN
    \item \textbf{Audit :} Journal des actions sensibles
\end{itemize}

\subsection{Paiement en Ligne}

\textbf{Architecture Abstraction :}
\begin{center}
Mobile App → Backend API → Payment Service → CMI/Provider
\end{center}

\textbf{Processus de Paiement CMI :}
\begin{enumerate}
    \item Client finalise sa commande dans l'app
    \item Backend crée une transaction CMI avec montant et référence
    \item Client redirigé vers interface sécurisée CMI (3D Secure)
    \item CMI traite le paiement et envoie webhook de confirmation
    \item Backend vérifie la signature du webhook
    \item Commande confirmée et restaurant notifié
    \item Client reçoit confirmation de paiement
\end{enumerate}

\textbf{Coûts CMI (estimatifs - à confirmer) :}
\begin{itemize}
    \item \textbf{Frais d'ouverture compte :} 1 000 - 2 000 MAD
    \item \textbf{Commission par transaction :} 2,5\% - 3,5\% + 2-5 MAD fixe
    \item \textbf{Abonnement mensuel :} 50 - 200 MAD/mois
    \item \textbf{Frais techniques intégration :} 500 - 1 500 MAD (une fois)
\end{itemize}

\textbf{Règles de Sécurité :}
\begin{itemize}
    \item Aucune donnée bancaire stockée côté Terrasse Bleue
    \item Confirmation serveur obligatoire via webhook signé
    \item Chiffrement TLS pour toutes communications
    \item Idempotence pour éviter les doubles paiements
    \item Support des remboursements via API CMI
    \item Journal d'audit de toutes les transactions
\end{itemize}
